# AI search validation runbook

Date: 2026-11-06

## Local verification completed

1. `pnpm typecheck` passes.
2. `pnpm build` passes and statically generates the homepage and six service URLs.
3. Public routes have server-generated metadata and visible semantic headings.
4. `/robots.txt` and `/sitemap.xml` are generated by Next.js metadata routes.

## Production verification required

These checks are **Not Verified** until performed against the deployed domain.

### Robots and sitemap

1. Request `https://aranax.tech/robots.txt` and confirm it returns HTTP 200, includes the sitemap URL, permits `OAI-SearchBot`, `Claude-SearchBot`, `Claude-User`, `PerplexityBot`, `Googlebot`, and `Bingbot`.
2. Request `https://aranax.tech/sitemap.xml`; confirm each listed URL returns HTTP 200 and its canonical points to the same HTTPS URL.
3. Check the deployment/CDN configuration for bot challenges, country restrictions, authentication, or rate limits that differ from browser traffic.

### Google Search Console

1. Verify ownership for the canonical domain property.
2. Submit `https://aranax.tech/sitemap.xml`.
3. Inspect the homepage and every service URL using URL Inspection; request indexing only after the page is final.
4. Monitor Page Indexing, Crawl Stats, and enhancement reports. A submitted sitemap or passing inspection does not guarantee ranking or inclusion in AI features.

### Bing Webmaster Tools

1. Verify the canonical site property and submit the sitemap.
2. Use URL Inspection for the homepage and service pages.
3. Review crawl information and any blocked-resource reports.

### Structured data

1. Use Google Rich Results Test and Schema.org Validator on the deployed homepage and a service page.
2. Confirm Organization/WebSite data matches approved business facts and Service/Breadcrumb URLs match the canonical page.
3. Do not add ratings, reviews, addresses, client counts, or social-profile links without verified source data.

### AI crawler access

1. Inspect server/CDN logs for permitted crawler requests and verify origin using the crawler vendor's current official guidance.
2. Confirm robots directives are read from the public frontend domain—not the Strapi host.
3. Record date, URL, user agent, verified source, response status, and any WAF action. Do not claim citation, ranking, or platform presence without observed evidence.

## Content validation

- Confirm each page’s direct-answer opening remains specific and accurate.
- Maintain descriptive internal links as case-study and article routes are added.
- Add bylines, author profiles, publication dates, and Article schema only when real editorial content is published.
